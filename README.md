# SpotiShuffler
Open source Python project which allows users to add a shuffled selection of songs from a specified playlist to their Spotify queue. 

Use the SpotiShuffler.lnk shortcut file to run the code. Requires Python to be installed. 
SpotiShuffler.lnk can be copy and pasted to desktop or to start menu for easier use of the code. 

If a browser tab opens when trying to use spotiShuffler, close the program and use SpotiShuffler_terminal.bat to run the code with terminal. When the browser tab opens again, once the link has finished redirecting, paste the link into the terminal to authorise use of the program. Once authorised, you can continue using the program from the shortcut.
